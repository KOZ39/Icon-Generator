# Icon Generator

[English](README.md) | 한국어 | [日本語](README_JA.md)

> VRChat 아바타와 액세서리의 아이콘을 만드는 유니티 에디터 도구입니다.

## 요구 사항

- Unity 2022.3.22f1
- Modular Avatar (선택)

## 설치

[VPM 저장소](https://koz39.github.io/vpm-listing/)에서 "Add to VCC"로 저장소를 추가한 뒤, VCC 또는 ALCOM의 프로젝트 관리에서 Icon Generator 패키지를 추가합니다.

## 사용법

1. 상단 메뉴에서 Tools > Icon Generator를 엽니다.
2. 소스에 아바타나 액세서리를 끌어다 놓습니다.
3. 미리보기를 보면서 카메라와 아이콘 설정을 조절합니다.
4. 아이콘 생성을 누릅니다.

## 주요 기능

- 합성 아이콘과 개별 아이콘을 한 번에 생성
- 소스 트리에서 촬영할 항목을 체크하거나 선택해 범위 지정
- 미리보기에서 마우스로 카메라 이동·회전·확대/축소
- 항목마다 다른 카메라 설정
- 보이는 부분 기준 구도, 잘림 방지, 배경색, 윤곽선
- 파일명 템플릿과 중복 파일 처리
- Modular Avatar의 Shape Changer, Material Setter, Material Swap 반영
- 저장한 아이콘을 MA 메뉴 아이콘에 자동 연결

## v1에서 업데이트

- 메뉴 위치가 Tools > 3D Obj to Icon에서 Tools > Icon Generator로 바뀌었습니다.
- 저장 폴더, 아이콘 크기, 확대/축소, 카메라 각도, 언어 설정은 처음 실행할 때 자동으로 옮겨집니다.
- 기본 파일명이 `{name}.png`로 바뀌어 v1로 만든 아이콘을 덮어쓰지 않습니다.
